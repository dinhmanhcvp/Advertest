THE PROBLEM

The Egocentric Collapse

State-of-the-art PII detection models excel on standard datasets (eye-level, static cameras). However, when deployed on body-mounted cameras (Ego4D), their performance plummets. Why?

3D Geometric Distortion

Fisheye lenses severely warp 3D space. Combined with chest-mounted angles, facial features are stretched beyond recognition.

ISP Auto-Exposure Lag

Tiny sensors fail to adjust quickly when transitioning from indoor to harsh sunlight, causing massive overexposure and HDR loss.

Dynamic Motion Blur

Continuous footsteps and rapid head rotations destroy high-frequency features needed for bounding box localization.

The Dilemma

Real Data Collection is Dead

Sending agents to record thousands of hours of real pedestrians from a chest-mount is expensive, unscalable, and poses a severe privacy risk (GDPR violation).

Standard 2D Augmentation (random crop, color jitter) completely fails to replicate these complex physical conditions.

THE SOLUTION

The 2-Phase Strategy

AdverTest's ultimate goal is simple: First, purposefully attack the model on ANY dataset to drastically reduce its accuracy and expose vulnerabilities. Second, generate a targeted adversarial dataset to retrain and improve the model.

1. Error Intelligence

Automatically extract "Hard Negatives" by analyzing model failure points using strict mathematical thresholds (IoU, Confidence).

2. Targeted Simulation

Dynamically chain physics-based corruptions that specifically target the identified root causes (e.g., applying blur only where the model fails on motion).

3. Physics Constraints

An Exclusion Matrix prevents the generation of physically impossible garbage data, ensuring every synthesized frame holds training value.

TARGETED SIMULATION

From Insight to Targeted Pool

Our Attack Engine isn't random. It ingests the Insight Dashboard from Label Studio and uses Dynamic Chaining to attack the model exactly where it's weakest.

error_fisheye Edge-weighted Grid Distortion

Distortion is aggressively applied at the image edges rather than a flat 2D stretch, accurately simulating the 3D projection of a spherical lens.

error_blur Multi-axis Motion Blur

Chaining Linear Blur (vertical footsteps) with Radial Blur (horizontal head turning) to replicate true kinetic noise.

error_overexposure Sensor Degradation

ToneCurve (HDR clipping) + ISONoise (low-light sensor static) + SunFlare (additive optical blooming).

Label Studio Error Baseline

error_blur 25%
error_overexposure 15%

The Engine at Work: Seeing this baseline, AdverTest allocates maximum GPU resources to generate 45% Fisheye-simulated data, aggressively targeting the exact knowledge gap holding the model back.

PHYSICS CONSTRAINTS

Preventing Garbage Data

Unconstrained augmentation yields impossible images that poison training. AdverTest employs rigorous geometric and physical constraints to preserve Data Integrity.

The Exclusion Matrix

Blocks mutually exclusive optical phenomena from combining:

SunFlare + LowLight HeavyFog + SunFlare
Bounding Box Integrity

Geometric warping severely bends GT labels. If a PII feature drifts beyond 50% of the image boundary, AdverTest automatically discards the sample to prevent label noise.

Severity Caps

Caps cumulative destruction. Ensures enough identifiable features remain so that the model (and humans) can still theoretically recognize the PII.

Auto-Triage (VLM)

Quality Gate

Before reaching the Human-In-The-Loop, a Vision-Language Model acts as a gatekeeper, instantly rejecting irrecoverably corrupted samples (Severity = 5).

Optimizes HITL Cost 1-Click Approval

FUTURE VISION (R&D)

Domain Translation via GenAI

Phase 1 (Mathematical IP) is production-ready. However, to solve the ultimate challenge of true 3D Depth & Camera Angles, Generative AI is our long-term solution.

ControlNet + Stable Diffusion

Preserve the exact PII identity using Facial Landmarks as a conditioning map, while SD completely reimagines the lighting, angle, and environmental distortion.
